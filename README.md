# Future Interns — Prompt Engineering Task 1

## AI Website Copy Generator for Local Businesses

### Project Overview

This project explores how prompt engineering can generate clear, persuasive, and website-ready content for local businesses.

The selected example business is **Glow Studio**, a beauty salon concept based in Hyderabad, Telangana, India.

Google Gemini is used to generate and refine business analysis, homepage copy, service descriptions, and calls to action through structured prompts.

A responsive website built with HTML, CSS, and JavaScript demonstrates how the generated content can be presented to potential customers.

## Project Objectives

* Understand the requirements of a local business.
* Define the target audience and brand voice.
* Generate homepage content with a clear value proposition.
* Create service descriptions tailored to the business.
* Write effective calls to action for appointment enquiries.
* Document reusable prompts and their corresponding outputs.
* Demonstrate the content through a responsive website.

## Prompt Engineering Workflow

The project follows a structured workflow:

1. **Business Analysis:** Identify business goals, audience, services, and brand voice.
2. **Homepage Generation:** Create the headline, subheadline, introduction, and homepage calls to action.
3. **Services Generation:** Produce clear and customer-focused service descriptions.
4. **CTA Generation:** Create booking, contact, and enquiry messages.
5. **Review and Refinement:** Evaluate the generated content for clarity, relevance, tone, and usability.
6. **Website Demonstration:** Present the content in a responsive website.

## Website Features

* Responsive homepage layout.
* Salon introduction and service descriptions.
* Appointment enquiry form.
* Service-specific booking links.
* Mobile navigation menu.
* WhatsApp booking request integration when configured.
* Contact section and footer.

The booking form prepares an enquiry. It does not independently confirm or store appointments.

## How to Run the Website

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using the Live Server extension, or open it directly in a browser.
4. Use an internet connection for externally hosted images and fonts.
5. Configure the salon's real WhatsApp number in `script.js` before testing WhatsApp booking requests.
